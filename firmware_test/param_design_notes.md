# パラメータ設計ノート

## 物理制約からの推定範囲

### 前提
- モータードライバ: DRV8825
- 電源: 24V
- 典型的なステッピングモーター: NEMA17 (200 steps/rev, 1.8°/step)
- RMT 解像度: 1 MHz (1 µs)

## 最大速度 (vmax) の目安

ステッピングモーターは高速になるほどトルクが低下する。
24V 駆動の NEMA17 の場合、概ね以下の範囲で脱調リスクが増大する:

| マイクロステップ | 安全域 (低リスク) | 上限目安 | RMT 上限 |
|:---:|---:|---:|---:|
| 1/1  | ≤ 3000 steps/sec | 6000 | 200000 |
| 1/2  | ≤ 5000 steps/sec | 10000 | 200000 |
| 1/4  | ≤ 8000 steps/sec | 16000 | 200000 |
| 1/8  | ≤ 5000 steps/sec | 10000 | 200000 |
| 1/16 | ≤ 5000 steps/sec | 10000 | 200000 |
| 1/32 | ≤ 3000 steps/sec | 6000  | 200000 |

※ 実際のモーター仕様・負荷・電流設定により大きく変動する。スイープで実測すること。

---

## 加速度 (accel/decel) の目安

加速度が大きすぎると起動・停止時に脱調する。

```
必要ステップ数 = vmax² / (2 × accel)

例: vmax=2000, accel=1000 → 停止距離 = 2000² / (2×1000) = 2000 steps
```

| accel [steps/sec²] | vmax=1000 の加速距離 | vmax=5000 の加速距離 |
|---:|---:|---:|
| 200   | 2500 steps | 62500 steps |
| 500   | 1000 steps | 25000 steps |
| 1000  |  500 steps | 12500 steps |
| 2000  |  250 steps |  6250 steps |
| 5000  |  100 steps |  2500 steps |
| 10000 |   50 steps |  1250 steps |

加速距離が TEST_STEPS (3200) より大きい場合は三角プロファイルになる（最高速未達）。

## スイープテスト戦略

### Phase 1: マイクロステップ選択
```
accel=1000 固定, vmax=2000 固定
microstep を 1,2,4,8,16,32 で切り替えて動作音・振動を確認
```
→ 最も滑らかに動作するマイクロステップを選択

### Phase 2: 最大速度探索（選択したマイクロステップで）
```
python param_sweep.py COM3 --find-max-speed --microstep 16 --accel 1000
```
→ 脱調しない最大速度を確認

### Phase 3: 加速度最適化（選択した vmax で）
```
python param_sweep.py COM3 --quick
```
→ 最大速度で脱調しない最大加速度を確認

### Phase 4: NVS に保存
```
SET MICROSTEP 16
SET VMAX 0 <最大速度 × 0.8>   ← 安全マージン 20%
SET ACCEL 0 <最大加速度 × 0.8>
SET DECEL 0 <最大加速度 × 0.8>
SAVE
```
